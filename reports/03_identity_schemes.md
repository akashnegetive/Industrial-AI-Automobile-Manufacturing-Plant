# Part B.3 – Identity schemes

Generated by `python -m ddn.identity`. The canonical key is the SAP functional location.

## Naming pattern per system

| System | Field | Pattern | Example | Quirks seen in the data |
|---|---|---|---|---|
| SAP PM asset master | `functional_location` | `DDN1-<shop>-<line>-<stn>-<equip>[-<comp>]` | `DDN1-BIW-L2-ST04-RB07` | Canonical key. Die ids contain '-' (DDN1-PRS-DIES-D-BSO-LH-03). |
| SAP PM asset master | `cmms_equipment_no` | `8-digit number, 1000xxxx` | `10007731` | Blank for structural levels (site/shop/line/station). |
| PI Historian | `tag_name` | `DDN1_<shop>_<line>_<equip>_<signal>.PV` | `DDN1_BIW_L2_R07_WELDCUR.PV` | No station in name; R07 not RB07; typos DD1_/DN1_; relocated robot keeps old name. |
| WinCC SCADA | `tag_name` | `PaintShop-<area>-<equip>-<signal>` | `PaintShop-Oven2-Z3-Temp` | Area spelled Oven2/OVN2/Ovn02, AHU/AirHandling; deg F. |
| S7 legacy OPC | `tag_name` | `<shop>.<line>.<equip>.<signal>` | `PRS.PL1.PR1.TON` | Sub-units glued to equipment: PR1HOL, PR2LUB. |
| MES tags | `tag_name` | `FA_<line>_<equip>_<signal>` | `FA_FN1_NR14_TQLAST` | Typos F_TR1, F_AFN1. |
| MES stations / RFID | `mes_station, reader_id` | `<line><n>-<nn>, RD-<station>` | `B2-04, RD-B2-04` | Own numbering: B2 = BIW L2, SLR-2 = sealer cell 2, F1 = FN1. No FL link. |
| Tool controllers | `tool_id` | `TCnn (= nutrunner NRnn), HW-07` | `TC14` | Channel number equals nutrunner number; HW-07 is a hand wrench. |
| Drawings | `labels` | `Line-coded numbers: RB-2nn, WG-2nn, TD-2.nn; ISA-5.1 TT-/TE-/MT-` | `RB-207, TE-423, AHU-02, BNR-B3, HD-03` | RB-207 = L2 robot 07; AHU-02 = AHU of booth B (TC2); BNR-B3 = oven B zone 3. |
| Alarms | `source` | `PLC object path, separator . _ /` | `BIW_L2_ST04_RB07, BIW/L2/S4/RB07` | Separators vary; station S4 vs ST04; MES station codes for andon. |
| Work orders | `equipment_no, functional_location_text, short_text` | `SAP no. (often blank/wrong), hand-typed FL fragment, free text` | `'R7 gun tip dressing fail', 'L2 ST4 robo'` | Nicknames, Hinglish, missing line number. |
| Defects | `inspection_point` | `MES station code of the inspection` | `BIQ-1, EOL-WT` | Never the causing equipment. |

## Mapping rules this implies (used in Part C)

- PI `R07` on line L2 -> robot RB07; station = ceil(07 / 2) = ST04 (two robots per station).
- MES `B<n>-<ss>` -> `DDN1-BIW-L<n>-ST<ss>`; `SLR-<n>` -> `DDN1-PNT-SL-ST0<n>`; `F1-<ss>` -> `DDN1-ASM-FN1-ST<ss>`.
- Tool `TCnn` -> nutrunner `NRnn` (its controller is `...-NRnn-TC`).
- Drawing `RB-2nn` -> line 2, robot nn; `AHU-01/02/03` -> AHUTC1 / AHUTC2 / AHUPR; zone `Bn` -> OV2-Zn.
- Alarm source: replace `.` `/` with `_`, `S<n>` -> `ST0<n>`, then it is the FL without `DDN1-`.
- Exception list: `L1ST3_RB5` tags -> `DDN1-BIW-L2-ST06-RB12` (relocated Mar-2026).
